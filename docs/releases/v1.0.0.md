WalidForge 1.0.0 brings portable engineering workflows and local tools for understanding a project, planning a change and reviewing the resulting evidence.

## Included

- 25 engineering skills covering architecture, backend, frontend/mobile, DevOps, testing, security, performance and delivery.
- Four review personas and nine lifecycle commands across three adapters.
- **Project Doctor** for read-only stack discovery and check-command provenance.
- **Change Compass** for evidence-linked candidate impact, planning snapshots and Git change review.
- A complete English user guide with installation choices, practical prompts and troubleshooting.

## Start here

Read [the User Guide](https://github.com/bnalwalid/walidforge-skills/blob/v1.0.0/docs/user-guide.md).

```bash
git clone --branch v1.0.0 https://github.com/bnalwalid/walidforge-skills.git
cd walidforge-skills
node scripts/forge.js doctor /path/to/project
node scripts/forge.js compass /path/to/project --intent "invoice retry" --kind bug
```

A clone includes the tools and shared resources; register skills through your host's supported mechanism. The validation workflow uses Node 22. Local CLI tools need no npm dependencies.

## Verification scope

Local tooling, catalog, routing, reference, command, artifact-path, version and hook checks are verified for this release. Compass candidates require inspection; review does not execute application checks or establish completion. Live model grading and real host/device compatibility are not certified by these local checks.
