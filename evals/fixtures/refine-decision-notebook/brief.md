# A rough developer tool idea

A developer proposes an AI architecture generator that automatically creates
microservices, CQRS and a deployment configuration from a paragraph. The only
observed pain is that their small team forgets why they rejected earlier options
and repeats design debates. No independent scaling or deployment need is known.

Refine the concept before writing a specification or code. Ask the sharpening
question that would change the direction, compare credible simpler approaches and
state the first useful outcome and an explicit Not Doing list. No user research or
market size estimates have been collected.
