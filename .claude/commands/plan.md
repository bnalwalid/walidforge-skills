Invoke walidforge-skills:planning-and-task-breakdown skill.

Task arguments: $ARGUMENTS

Identify the active specification or clear requirements and selected module. Inspect unfinished work before writing tasks/plan.md and the default task list target tasks/todo.md. Use the designated external tracker when one exists.

Plan vertical outcomes with explicit prerequisites, acceptance criteria and verification. Schedule important uncertainties early and place checkpoints at integration or transition boundaries. Preserve incomplete plans; do not overwrite another objective.

Deliver the ordered plan, architecture consequences, blockers and next ready task. This command plans; it does not implement the feature.
